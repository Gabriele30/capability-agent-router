# CAR 0.4.0 — Routing Intelligence

CAR 0.4.0 establishes the routing-intelligence layer. It deterministically
analyzes software-engineering tasks, consults Gemini only when that evidence may
add value, and conservatively combines both signals into a final route.

## Highlights

- Deterministic task analysis, repository intelligence, and explainable routes.
- Verified L0 execution for supported deterministic formatting and lint-fix work.
- Gemini structured classification with local configuration checks, timeout,
  retry, normalized errors, and explicit opt-in live validation.
- Lazy consultation: formatting resolves to L0 and authentication bypasses route
  to hard-rule Codex without calling Gemini; eligible uncertain tasks may consult it.
- Conservative fusion: `GEMINI < GEMINI_TO_CODEX < CODEX`; provider evidence may
  escalate but cannot downgrade a route. The default escalation-confidence threshold
  is 0.70.
- Unified `car analyze` / `car task` routing, local-only `car providers`, and
  machine-readable routing evaluation JSON.

## Safety

Provider failures preserve the deterministic route. Gemini credentials are read
from the environment and never persisted. L0 snapshots, verifies, and rolls back
failed operations while preserving pre-existing user changes.

## Known limitations

Gemini classification is implemented, but Gemini coding execution is not.
Codex is a routing target only: Codex coding execution and Gemini-to-Codex coding
handoff are not implemented. VS Code integration is not implemented.

# CAR 0.5.0

Capability Agent Router 0.5.0 introduces the first complete, verified coding
execution pipeline.

## Highlights

- Deterministic task routing and explicit user-authorized `car execute`.
- Gemini coding through structured proposals only.
- CAR-owned patch validation, transactional application, verification presets, and
  rollback on failed verification.
- Gemini-to-Codex post-failure handoff with local Codex read-only diagnostics.
- Structured execution-result UX, Windows resolved-executable support, and current
  Codex global-option ordering compatibility.
- Opt-in live integration validation of both successful and rollback/escalation
  paths using synthetic repositories.

## Safety

- Codex remains read-only and never writes repository files.
- CAR does not manage provider or Codex credentials.
- Verification commands are CAR-controlled; arbitrary commands are not accepted.
- Pre-existing user changes are protected, and failed verified attempts are rolled
  back.
- A successful read-only Codex diagnostic does not resolve the coding task.

## Live validation

- C1: Gemini proposal → safe apply → verification pass.
- C2: Gemini proposal → safe apply → intentional verification failure → rollback
  → clean workspace → read-only Codex diagnostic.
